# Анализ онлайн-продаж

Цель - понять, почему прибыль падает при стабильном количестве покупок.

Выводы:
1. Наиболее дорогие товары - электроника.
2. Самые продаваемые товары - одежда и книги.
3. В мае начался спад прибыли, но при этом количество покупок по месяцам не менялось, то есть люди стали покупать менее дорогие товары (электроника). Рекоменловано сделать скидки на электронику, чтобы стимулировать спрос.

Используемые библиотеки Python: pandas, numpy, seaborn, matplotlib.

Источник данных - https://www.kaggle.com/datasets/shreyanshverma27/online-sales-dataset-popular-marketplace-data/data
